# 标准（内部）专利申请表模板

> **适用类型**: 公司内部标准化专利申请表（含权利要求书、摘要）
> **本质**: 可直接提交至专利局的最终专利申请文件
> **适用场景**: 公司内部直接申请专利，无需经过外部专利代理机构
> **与 ACIP 交底书的差异**: 本模板包含"权利要求书""摘要""说明书附图"等专利法强制要求的最终文件章节

---

## 输出结构（严格按此顺序）

### # 摘要

- ≤ 300 字
- 单段
- 不得包含权利要求式限定语
- 指明一幅最有代表性的摘要附图

格式：
```markdown
# 摘要

[发明名称、所属技术领域、要解决的技术问题、核心技术方案与主要技术效果的简要说明]

摘要附图：图[X]
```

---

### # 背景技术

- 现有技术状况
- 存在的问题
- 技术挑战

---

### # 检索分析

撰写提案前必须经过充分检索。

```markdown
1. 检索关键词：[技术领域 + 技术效果 + 技术特征]
2. 检索式：[查询语句]
3. 检索结果

| 编号 | 申请号 | 专利名称 | 发明内容 |
|-|-|-|-|
| 1 | [申请号] | [专利名称] | [发明内容] |
| 2 | ... | ... | ... |
| 3 | ... | ... | ... |

4. 检索结果分析
与本提案最接近的专利为 [专利号]，该专利要解决的技术问题是 [X]，所采用的技术方案是 [Y]，起到的效果是 [Z]。本提案要解决的技术问题是 [X']，所采用的技术方案是 [Y']，起到的效果是 [Z']。本提案与该发明的相同点是 [A]，区别点是 [B]。

| 最接近的现有技术专利申请号 | 与本提案的相同点 | 与本提案的区别点 |
|-|-|-|
| [申请号] | [相同点] | [区别点] |
| ... | ... | ... |
```

---

### # 发明内容

1. 本发明要解决上述技术问题中最核心的技术问题是 [核心问题]
2. 从宏观上看，解决技术问题的技术方案可以概括提炼为 [方案概述]
3. 技术方案带来的有益效果体现在 [有益效果]

---

### # 权利要求书

撰写要求：
- 独立权利要求 1-3 条（发明 / 方法 / 系统），采用「前序部分 + 其特征在于」二段式
- 从属权利要求 10-20 条，覆盖优选实施方式与 fallback 位置
- 每条从属权利要求必须正确引用在前的权利要求（"根据权利要求 1 所述的..."）
- 所有用语须在说明书中有充分支持（专利法第 26 条第 4 款）

```markdown
1. 一种[技术领域]的[方法/系统/装置]，其特征在于，包括：
   [前序部分：已知技术特征]；
   其特征在于：
   [区别技术特征：核心创新点]。

2. 根据权利要求 1 所述的[方法/系统/装置]，其特征在于，[从属技术特征]。

3. 根据权利要求 1 所述的[方法/系统/装置]，其特征在于，[fallback 位置]。

...（继续至 10-20 条）
```

---

### # 说明书附图

## 附图说明

- 图 1 为本发明实施例提供的 [系统/方法/装置] 的整体架构示意图
- 图 2 为本发明实施例提供的 [核心流程] 的方法流程图
- 图 3 为本发明实施例提供的 [关键模块/数据结构] 的示意图
- 图 4 为本发明实施例提供的 [替代实施方式] 的对比示意图

> 附图要求：
> - 参考标号统一编排（10、20、30... 整十递增），贯穿说明书与权利要求书保持一致
> - 由 `patent-figforge` skill 生成 SVG/PNG，标注"正式申请需替换为专利制图"

---

### # 具体实施方式

至少 3 个实施例，每个实施例有明确差异：

```markdown
## 实施例一：[场景]
[详细描述]

## 实施例二：[场景]
[详细描述]

## 实施例三：[场景]
[详细描述]
```

变化维度（必选 3 项，从以下维度中各选一个方向）：
- 数据流向（push/pull, sync/async）
- 触发条件（time-based, event-based, threshold-based）
- 模块边界（monolithic, distributed, edge-cloud）
- 处理位置（local, remote, edge）

## 质量自检清单（标准申请表专属）

- [ ] 摘要 ≤ 300 字，单段，含摘要附图
- [ ] 检索分析含 ≥ 3 篇对比专利
- [ ] 权利要求书：独立 1-3 条 + 从属 10-20 条
- [ ] 从属权利要求引用基础正确
- [ ] 说明书支持所有权利要求（专利法 26.4）
- [ ] 充分公开（专利法 26.3 / enablement）
- [ ] IPC 分类号已识别
- [ ] 说明书附图 ≥ 3 幅，参考标号统一
- [ ] 具体实施方式 ≥ 3 个实施例
- [ ] 创新点、替代方案、缺陷齐全
