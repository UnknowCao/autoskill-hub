# Domain Adaptation Matrix（领域适配矩阵）

> **用途**: patent-forge Phase 3A Action 3 / 5 / 6 的**单一事实源**。按 Phase 1 Action 1 识别的技术领域，从本矩阵选取对应的 claims 范式 / 实施例变化维度 / 附图类型。**禁止跨领域套用**（Anti-Pattern #16）。
>
> **位置**: `references/domain_matrix.md`（相对于 skill 根目录）。

---

## 领域判定（Phase 1 Action 1 输出）

将发明归入以下 6 类之一：

| 领域 | 判定特征 | 典型关键词 |
|---|---|---|
| **软件/算法类** | 核心创新在数据处理/算法/控制逻辑 | 方法、模型、算法、推荐、识别、学习 |
| **机械/结构类** | 核心创新在物理结构/连接关系/运动机构 | 装置、结构、机构、铰接、折叠、装配 |
| **电子/电路类** | 核心创新在电路拓扑/信号链/元件选型 | 电路、传感器、电源、信号、转换器 |
| **化学/材料类** | 核心创新在组分/配比/合成条件/材料 | 组合物、配方、聚合物、合成、制剂 |
| **混合类（HW+SW）** | 硬件结构 + 控制方法均有创新 | 系统 + 方法、装置 + 控制 |
| **不确定领域** | Phase 1 信息不足以唯一判定 | 默认按"实现机制/结构配置/操作条件"变化 |

## § 1 Claims 范式（Phase 3A Action 3 加载）

按领域选择权利要求撰写范式。独立权利要求 1-3 条（二段式「前序部分 + 其特征在于」）+ 从属权利要求 10-20 条。

### 软件/算法类

**权利要求类型组合**：方法权利要求 + 系统权利要求 + 程序存储介质权利要求（fallback 位置）

```
1. 一种[技术领域]的[方法名称]方法，包括：
   [前序部分：已知技术特征]；
   其特征在于：
   [区别技术特征：核心创新步骤]。

8. 一种[系统名称]系统，包括：
   [模块 X]，配置为[功能]；
   [模块 Y]，配置为[功能]。

14. 一种计算机可读存储介质，其上存储有计算机程序，其特征在于，
    该程序被处理器执行时实现权利要求 1 至 7 中任一项所述方法的步骤。
```

完整 dogfood 示例：[`application_example.md`](./application_example.md)（Focus Period 推荐系统，14 条权利要求含方法/系统/介质三类）

### 机械/结构类

**权利要求聚焦**：位置关系 + 连接关系 + 配合关系，每条限定**必须含参考标号**（10/20/30...）

```
1. 一种[装置名称]，包括底座(10)、立柱(20)和[部件](30)，其特征在于：
   所述[部件](30)通过[铰接/滑轨/螺纹]连接于所述立柱(20)的[位置]，
   并被配置为在[工作状态]下[运动/姿态]，在[收纳状态]下[另一姿态]；
   [锁定机构](40)被配置为将所述[部件](30)固定于[工作位置/收纳位置]。

2. 根据权利要求 1 所述的[装置]，其特征在于，所述[部件](30)的[几何参数]
   满足[数值范围]，使得[技术效果]。
```

**必须覆盖**：连接类型（铰接/滑接/螺纹）、运动自由度、锁定机构、几何参数范围

完整 dogfood 示例：[`application_example_mechanical.md`](./application_example_mechanical.md)（可折叠充电桩，14 条权利要求，参考标号 10-83）

### 电子/电路类

**权利要求聚焦**：电路拓扑 + 信号链 + 元件选型

```
1. 一种[系统名称]，包括传感器单元、信号调理单元、模数转换单元和处理单元，
   其特征在于：
   所述信号调理单元包括[具体电路拓扑]，
   被配置为[信号处理功能]；
   所述处理单元被配置为[基于所述模数转换单元的输出执行算法]。
```

### 化学/材料类

**权利要求聚焦**：组分 + 含量范围 + 制备步骤

```
1. 一种[组合物名称]，其特征在于，按重量份计，包括：
   组分 A：x-y 份；
   组分 B：m-n 份；
   组分 C：p-q 份；
   所述组分 A 与组分 B 的重量比为 [范围]。

2. 根据权利要求 1 所述的[组合物]，其特征在于，所述组合物的制备方法包括：
   [步骤 1]；[步骤 2]；[步骤 3]。
```

> **范围表达**：用「至」或「x-y 份」，禁止「大约/优选地」（Anti-Pattern #8）

### 混合类（HW+SW）

组合上述范式：硬件结构用机械/电子范式（含参考标号），控制方法用软件范式。**两类权利要求都要写**。

**判定子型**（重要）：除"系统+方法/装置+控制"显式配对词外，"硬件为常规载体 + 算法/控制逻辑为核心创新"也归混合类（如 BMS 算法、传感器信号处理+估计算法、电机驱动+控制策略）。

完整 dogfood 示例：[`application_example_hybrid.md`](./application_example_hybrid.md)（BMS SOH 监测，14 条权利要求：硬件含参考标号 10-40 + 方法权利要求，4 实施例跨硬件配置×控制方法 2 维度）

### 不确定领域

默认采用「实现机制 / 结构配置 / 操作条件」三维度变化，撰写时向用户追问以确定主导领域。

## § 2 实施例变化维度（Phase 3A Action 5 加载）

至少 3 个可区分的实施例，**变化维度必须匹配技术领域**。

| 领域 | 变化维度 1 | 变化维度 2 | 变化维度 3 | 变化维度 4 |
|---|---|---|---|---|
| **软件/算法类** | 数据流（push/pull, sync/async）| 触发条件（time/event/threshold）| 架构（monolithic/distributed/edge-cloud）| — |
| **机械/结构类** | 驱动方式（电动/气动/手动）| 折叠几何（铰接/滑轨/伸缩）| 材料（金属/复合材料）| 锁定机构（卡扣/磁吸/螺纹）|
| **电子/电路类** | 电路拓扑 | 元件选型 | 信号处理链 | 电源管理方案 |
| **化学/材料类** | 组分配比 | 合成方法 | 加工条件 | 添加剂选择 |
| **混合类** | 硬件配置（取上述对应维度）| 控制方法（取软件维度）| — | — |
| **不确定领域** | 实现机制 | 结构配置 | 操作条件 | — |

**铁律**：每个实施例至少变化 1 个维度；3 个实施例不能只变同一个维度。

## § 3 附图类型（Phase 3A Action 6 加载）

至少 3 幅附图，**图类型必须匹配技术领域**。

| 领域 | 图 1（整体）| 图 2（核心）| 图 3（细节/原理）|
|---|---|---|---|
| **软件/算法类** | 整体架构图 | 核心方法流程图 | 关键模块示意图 |
| **机械/结构类** | 整体结构图（装配图）| 关键部件详图 | 工作原理图/运动简图 |
| **电子/电路类** | 系统框图 | 电路原理图 | 信号流图 |
| **化学/材料类** | 工艺流程图 | 结构式/组成图 | 性能对比图 |
| **混合类** | 整体三维结构图 | 工作原理图 | 控制流程图 / 电路图 |
| **不确定领域** | 整体示意图 | 核心原理图 | 参数标注图 |

**参考标号规则**：统一编排（10、20、30... 整十递增），贯穿说明书与权利要求书一致。

**附图生成归属**：所有附图由 `patent-figforge` skill 生成 SVG/PNG，本 skill 仅指定图类型和内容要求。生成后标注「正式申请需替换为 Visio (.vsd) / CAD 原图」。
