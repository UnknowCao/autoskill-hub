Real output samples generated by patent-figforge. Each file pair (SVG + PNG)
was produced by a single API call and passed all 3 compliance GATEs.

## Regenerate

```bash
cd patent-figforge
python scripts/generate_showcase.py
```

Or manually:

```python
from python.diagram_generator import PatentDiagramGenerator
gen = PatentDiagramGenerator(output_dir="examples")

gen.create_block_diagram(
    blocks=[
        {"id":"vadc","label":"电压采集单元","ref":10},
        {"id":"mcu","label":"主控MCU","ref":20},
        {"id":"comm","label":"通信模块","ref":30},
        {"id":"bal","label":"均衡驱动","ref":40},
    ],
    connections=[["vadc","mcu"],["mcu","comm"],["mcu","bal"]],
    filename="bms-block", output_format="svg", rankdir="LR"
)
```
